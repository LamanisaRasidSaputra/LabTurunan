Tentang Aplikasi

Simulasi TKA — Matematika: Turunan Fungsi adalah lab maya interaktif untuk membantu siswa SMA Fase F memahami dan berlatih konsep turunan fungsi aljabar hingga trigonometri, sesuai kisi-kisi Tes Kemampuan Akademik (TKA).

Teknologi

Dibangun sepenuhnya dengan teknologi web standar, berjalan langsung di peramban tanpa instalasi tambahan.

HTML5 CSS3 JavaScript Canvas API Web Audio API

Kompetensi yang Dilatih

  • Pengetahuan matematika
  • Representasi matematis
  • Penalaran dan pembuktian matematis
  • Pemecahan masalah matematis
  • Koneksi matematis

Cakupan Muatan

Turunan fungsi aljabar (aturan pangkat, jumlah/selisih, hasil kali, hasil bagi, rantai) sampai dengan turunan fungsi trigonometri dan penerapannya.

Pengelolaan & Privasi Data

Setiap sesi latihan tercatat: nomor peserta, nama, kelas, bidang studi, waktu mulai/selesai, durasi, skor akhir, dan rincian jawaban per soal. Data ini dikirim ke Google Sheets milik pengajar untuk keperluan pemantauan hasil belajar, dan tidak dipublikasikan atau dibagikan ke pihak lain.

Nomor peserta dibuat otomatis & berurutan per perangkat (tersimpan di localStorage peramban). Jika koneksi internet terputus saat pengiriman, data disimpan sementara di perangkat dan akan dicoba dikirim ulang otomatis saat aplikasi dibuka kembali.

Status Data Tertunda

Jika sebelumnya ada hasil latihan yang gagal terkirim ke Google Sheets, gunakan tombol berikut untuk mencoba mengirimkannya kembali.

Catatan

Aplikasi ini merupakan media pembelajaran mandiri dan tidak berafiliasi resmi dengan penyelenggara TKA manapun. Soal disusun sebagai bahan latihan konsep, bukan bank soal resmi.
